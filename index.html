Why these tools are private

Each tool here is a single self-contained web page. All the work — reading a photo's metadata, parsing a URL, matching an error string — happens in JavaScript running on your own device. There is no server receiving your input, because there is nothing to send it to.

That means you can check a sensitive photo or a suspicious link without handing either one to a third party. Nothing is stored, logged, or transmitted.
